TFT YouTube Uploader

本サイトは、TFT分析動画をチャンネル所有者本人がYouTubeにアップロードするための、個人用ツールの説明ページです。

主な機能

動画・サムネイルの確認、手動承認によるYouTubeへの非公開アップロード、投稿先チャンネルの確認、重複投稿の検出、アップロード結果の確認を行います。動画の公開はYouTube Studioで別途手動で行います。

使用するデータ

YouTube API Servicesを使ってチャンネル情報、最近の投稿動画のタイトル・ID・公開状態、アップロード結果を確認します。許可された動画のアップロード以外には投稿権限を使用しません。

プライバシーポリシーをご確認ください。本ツールの利用にはYouTube利用規約が適用されます。
